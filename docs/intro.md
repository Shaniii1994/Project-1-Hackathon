# Introduction

Welcome to the ROS 2 for AI Students course. This educational module is designed for AI students with basic Python knowledge who are new to robotics.

This course will teach you how to connect AI logic with humanoid robot control using ROS 2 as middleware. You'll learn the fundamentals of ROS 2, how to integrate Python with ROS using rclpy, and how to model humanoid robots using URDF.
