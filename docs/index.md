# ROS 2 for AI Students

Welcome to the ROS 2 for AI Students educational series. This comprehensive course is designed for AI students with basic Python knowledge who are new to robotics.

## Module 1: The Robotic Nervous System (ROS 2)

This module covers the fundamentals of ROS 2 as middleware connecting AI logic to humanoid robot control. You'll learn:

- Core ROS 2 concepts: nodes, topics, services
- Python integration with rclpy
- Humanoid robot modeling with URDF

### Learning Path

1. **[Introduction](./ros-module-1/introduction.md)** - Overview of the module and learning objectives
2. **[Chapter 1: ROS 2 Foundations](./ros-module-1/chapter-1-foundations/index.md)** - Core concepts and the "nervous system" analogy
3. **[Chapter 2: Python to ROS with rclpy](./ros-module-1/chapter-2-python-integration/index.md)** - Connecting Python with ROS 2
4. **[Chapter 3: Humanoid Modeling with URDF](./ros-module-1/chapter-3-urdf-modeling/index.md)** - Robot modeling and kinematics

### Educational Approach

This course takes a practical, hands-on approach to learning ROS 2:

- **Conceptual Understanding**: Learn the theory behind ROS 2 architecture
- **Practical Implementation**: Write code examples and build systems
- **AI Integration**: Connect AI algorithms with robotic systems
- **Real-world Applications**: Apply concepts to humanoid robotics

### Prerequisites

- Basic Python programming knowledge
- Understanding of fundamental programming concepts
- Interest in robotics and AI integration

### What You'll Build

By the end of Module 1, you'll have created:

- A complete ROS 2 system with multiple communicating nodes
- Python-based publishers, subscribers, and services
- A humanoid robot model in URDF
- An integrated system connecting AI logic with robot control
